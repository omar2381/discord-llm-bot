discord-llm-bot

Games, utilities and moderation for your server, plus an AI assistant that runs on a local model instead of a paid API.

Add to Server Source on GitHub

What it does

Everything except the assistant works with no AI configured at all.

Games

Seven-way rock-paper-scissors played over buttons, dice in 2d6+1 notation, and an 8-ball.

Moderation

Kick, ban, timeout, purge and warnings, each re-checking role hierarchy before it acts. Every action can go to a mod-log channel.

Auto-moderation

A banned-word list that sees through stretched spellings and zero-width characters, and spam detection for bursts and repeats.

Welcome & roles

Greet new members with a message you write, hand out a role automatically, and post menus people click to pick their own roles.

Utilities

Reminders that survive a restart, native Discord polls, server and member information.

An assistant, optionally

Mention it and it answers. It can remember things about you, set reminders and post polls, and it asks before anything destructive.

Commands

Twenty-five in all. Moderation commands are hidden from members who cannot use them.

Fun
  • /rps Challenge someone; they accept with a button and pick in secret
  • /roll Dice, up to 100 of them, up to 1000 sides
  • /8ball The usual twenty answers
Utility
  • /remind Set, list and cancel reminders
  • /poll A native Discord poll, 2 to 10 options
  • /serverinfo Members, channels, roles, owner, age
  • /userinfo When someone joined, and their roles
  • /ping Latency, both kinds
  • /help Everything, grouped
Moderation
  • /kick Remove a member
  • /ban Ban, optionally deleting their recent messages
  • /timeout Stop someone talking, up to 28 days
  • /untimeout Lift it early
  • /purge Delete up to 100 messages, optionally from one person
  • /warn Record a warning and tell them
  • /warnings List or clear someone's warnings
  • /modlog Choose where actions are recorded
  • /automod Banned words and spam detection
Community
  • /welcome Greet new members, with a preview before it goes live
  • /autorole Give everyone who joins a role
  • /rolemenu Post buttons people click to pick roles
Assistant
  • /ask Ask it something, privately if you like
  • /memory See, delete, or stop it remembering anything about you
  • /ai Switch the assistant on or off for the server

About the assistant

It is a small model running on the machine that hosts the bot. Nothing is sent to OpenAI, Anthropic or anyone else, and there is no per-message cost.

What it will and will not do
  • It answers when you mention it, reply to it, or use /ask. It does not join conversations uninvited.
  • It reads the last dozen messages of the channel for context when you ask it something, and keeps none of them.
  • It can remember short facts about you, per server. /memory view shows them and /memory optout deletes the lot and stops it storing more.
  • It can set reminders and post polls on your behalf.
  • Anything destructive — a timeout, deleting messages, changing roles — comes back as a button only you can press, and your permissions are checked again when you do.
  • It is never given kick or ban, and it always acts with your permissions, never its own.

Run your own

There is no public instance: the bot is free to run because it runs on hardware someone already owns. Yours can be a spare PC, a Raspberry Pi, or a free ARM instance.

  1. Create an application in the Discord Developer Portal, copy the token, and enable the Server Members and Message Content intents.
  2. Clone and configure. Copy .env.example to .env and fill in the token, application id and your server id.
  3. Start it.
    npm ci
npm run deploy:commands
npm run dev
  4. Add the assistant, if you want one. Install Ollama, pull a small model, and point OLLAMA_URL at it. Leave it empty and everything else still works.
    ollama pull qwen2.5:3b
npm run check:ai
